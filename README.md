# BreadVPNShop - simple digital market

> Very simple bot to send some text strings to your users and check payments (of course, please don't use this for sending VLESS configs :D )

---

## 🔹 Functions

*   Send text strings
*   Check payments
*   Love RKN so much

---

## 🚀 Install

Clone repo:

```
git clone https://github.com/mihailovily/BreadVPNShop.git
cd BreadVPNShop
```

Install requirements:

```
poetry update
```

Configure enviroment:

```
# Just copy .env.example to .env and edit by yourself:

cp .env.example .env   # Linux / macOS
copy .env.example .env # Windows
```

Run code:

```
poetry run python3 main.py
```
